SNUG ARCHIVE — ПУБЛИКАЦИЯ НА GITHUB PAGES

1. Распакуйте snug-archive-site.zip целиком.
2. Откройте GitHub Desktop и создайте репозиторий из распакованной папки.
3. Сделайте Commit и Publish repository.
4. На GitHub откройте Settings → Pages.
5. Source: Deploy from a branch; Branch: main; Folder: /(root); затем Save.
6. Через несколько минут ссылка появится в блоке GitHub Pages.

Важно: корневой index.html и все папки b_* должны лежать рядом.
Случайные имена папок не являются защитой: любой, у кого есть ссылка на главную, увидит все доски.
